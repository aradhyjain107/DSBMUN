DSB MUN 5.0 Vercel Developer Resources & API Docs

Welcome to the official developer and machine documentation for DSB MUN 5.0. This interface provides REST endpoints, OpenAPI 3.1 specifications, Model Context Protocol (MCP) server endpoints, Vercel serverless integration, authentication docs, and structured content negotiation for AI agents.

Authentication & Auth Docs

Open Public Access: All read and query endpoints are public and require no API key or credentials.

API Versioning: All endpoints are versioned under the /v1/ path (e.g. https://dsbmun.vercel.app/v1/info). Unversioned aliases (/api/*) route to the current active major version (v1).

Rate Limits: Standard rate limits are set to 100 requests per minute. Headers returned with responses include RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset, X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset.

OpenAPI 3.1 Specification

The machine-readable OpenAPI 3.1.0 specification is available at:

  • OpenAPI JSON: https://dsbmun.vercel.app/v1/openapi.json (or /openapi.json)
  • Compatibility: Fully typed request and response schemas (7/7 operations) compatible with Vercel AI SDK, OpenAI function calling, and LangChain.

Model Context Protocol (MCP) Server

For AI assistants (Claude, Cursor, ChatGPT), DSB MUN 5.0 provides a first-party HTTP MCP server adhering to the 2024-11-05 protocol specification.

  • Live Protocol Handshake: https://dsbmun.vercel.app/.well-known/mcp
  • Physical Manifest: https://dsbmun.vercel.app/.well-known/mcp.json
  • Streamable HTTP Transport: https://dsbmun.vercel.app/api/mcp
  • Tools Exposed: get_conference_info, list_committees, get_schedule, get_dress_code, get_contact_info.
curl -X POST https://dsbmun.vercel.app/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"tools/call","params":{"name":"list_committees"},"id":1}'

Webhooks & Event Streaming

DSB MUN 5.0 supports streaming JSON-RPC tool executions via the Streamable HTTP transport at /api/mcp. Conference announcements and updates are pushed through semantic markdown feeds at /llms.txt and /llms-full.txt.

REST Typed Error Models (RFC 9457 Problem Details)

All 4xx and 5xx responses return structured RFC 9457 application/problem+json and application/json error models with machine-readable error codes and resolution hints:

{
  "code": "NOT_FOUND",
  "message": "The requested resource was not found.",
  "resolutionHint": "Check /v1/openapi.json or /docs for available endpoints.",
  "statusCode": 404
}

API Deprecation & Sunset Policy

DSB MUN 5.0 follows Semantic Versioning 2.0.0 for all machine interfaces:

  • Deprecation Signaling: Deprecated APIs return standard HTTP response headers: Deprecation: true, Sunset: <date> (per RFC 8594), and a Link: <url>; rel="deprecation" header.
  • Deprecation Timeline: Any major version deprecation is announced at least 90 days in advance before sunsetting.
  • Current Active Version: v1 (Active, Deprecation: false).

REST API Endpoints

GET /v1/info

Returns general conference overview metadata including dates, theme, venue, and committee count.

curl -s https://dsbmun.vercel.app/v1/info

GET /v1/committees

Returns list of all 9 simulation committees (UNHRC, UNSC, Lok Sabha, AIPPM, UNGA, UNCSW, IP, IPL Auction, UNCLOS) with agendas and grade eligibility.

curl -s https://dsbmun.vercel.app/v1/committees

GET /v1/schedule

Returns hour-by-hour schedule breakdown for Day 1 (1 August 2026) and Day 2 (2 August 2026).

curl -s https://dsbmun.vercel.app/v1/schedule

GET /v1/dress-code

Returns delegate dress code requirements (Day 1: Indian Traditional, Day 2: Western Formal).

curl -s https://dsbmun.vercel.app/v1/dress-code

GET /v1/contacts

Returns Secretariat email, Instagram handle, and host school details.

curl -s https://dsbmun.vercel.app/v1/contacts

Content Negotiation (acceptmarkdown.com)

To receive raw Markdown representations of the site, include Accept: text/markdown header in HTTP requests:

curl -H "Accept: text/markdown" https://dsbmun.vercel.app/
