DSB MUN 5.0 Developer API Documentation

Welcome to the official developer and machine documentation for DSB MUN 5.0. This interface provides REST endpoints, OpenAPI 3.1 specifications, Model Context Protocol (MCP) server endpoints, and structured content negotiation for AI agents and developers.

Authentication & Rate Limits

Authentication: All GET endpoints are public and require no API key or authentication.

Rate Limits: Standard rate limits are set to 100 requests per minute. Headers returned with responses include X-RateLimit-Limit and X-RateLimit-Remaining.

Machine Specifications

  • OpenAPI 3.1 Spec: https://dsbmun.vercel.app/openapi.json
  • Model Context Protocol Manifest: https://dsbmun.vercel.app/.well-known/mcp.json
  • Agent Instruction Spec: https://dsbmun.vercel.app/llms.txt
  • Full Machine Spec: https://dsbmun.vercel.app/llms-full.txt

REST API Endpoints

GET /api/info

Returns general conference overview metadata including dates, theme, venue, and committee count.

curl -s https://dsbmun.vercel.app/api/info

GET /api/committees

Returns list of all 9 simulation committees (UNHRC, UNSC, Lok Sabha, AIPPM, UNGA, UNCSW, IP, IPL Auction, UNCLOS) with agendas and grade eligibility.

curl -s https://dsbmun.vercel.app/api/committees

GET /api/schedule

Returns hour-by-hour schedule breakdown for Day 1 (1 August 2026) and Day 2 (2 August 2026).

curl -s https://dsbmun.vercel.app/api/schedule

GET /api/dress-code

Returns delegate dress code requirements (Day 1: Indian Traditional, Day 2: Western Formal).

curl -s https://dsbmun.vercel.app/api/dress-code

GET /api/contacts

Returns Secretariat email, Instagram handle, and host school details.

curl -s https://dsbmun.vercel.app/api/contacts

Model Context Protocol (MCP) Server

For AI assistants like Claude, ChatGPT, and Cursor, DSB MUN 5.0 exposes a native HTTP MCP server at https://dsbmun.vercel.app/api/mcp with tools: get_conference_info, list_committees, get_schedule, get_dress_code, and get_contact_info.

curl -X POST https://dsbmun.vercel.app/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"tools/call","params":{"name":"list_committees"},"id":1}'

Content Negotiation (acceptmarkdown.com)

To receive raw Markdown representations of the site, include Accept: text/markdown header in HTTP requests:

curl -H "Accept: text/markdown" https://dsbmun.vercel.app/

JSON Error Schema

All 404 or API errors return structured JSON when requested with Accept: application/json or on /api/* endpoints:

{
  "error": {
    "code": "NOT_FOUND",
    "message": "The requested path '/api/invalid' was not found on DSB MUN 5.0.",
    "resolutionHint": "Refer to /openapi.json, /docs, or /llms.txt for available API endpoints.",
    "statusCode": 404
  }
}
