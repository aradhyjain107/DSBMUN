# Design Specification — DSB MUN 5.0

Refer to [design.md](file:///Users/aradhy/Desktop/MUN/design.md) for the complete 16-part design specification.

## Core Visual DNA & Tokens
- **Substrate**: Warm paper off-white (`--paper: #F2EBDC`).
- **Primary Navy**: Opaque navy (`--navy: #0E2A8A`).
- **Accent Palette**: `--red: #C8281C`, `--lime: #B8D62E`, `--yellow: #F0B800`, `--sky: #1D70B8`.
- **Cyan Misregistration**: `--tint-cyan: #00E5FF` offset ghost shift on hover (`translateX(-3px)`).
- **Typography**:
  - Display / Headlines: `Bebas Neue`
  - Accent Words: `Georgia` (italic)
  - Body: `Inter`
- **UI Primitives**:
  - Mac OS X Window Chrome (Brushed metal gradient, `#FF5F57`, `#FEBC2E`, `#28C840` traffic lights, hard 2px/4px black shadow).
  - Rotated ±2° Sticker Tape Headers.
  - Starburst Polygon CTA Buttons.
- **Anti-Slop Directives**:
  - No generic dark blue glassmorphism navbar.
  - No monochrome/grayscale leadership photos.
  - No equal uniform grid boxes without rhythm.
